# 나의 서재

메모를 남기면 한 편의 글로 완성해 분류별로 꽂아 두고, 캘리그라피 작품을 함께 걸어 두고,
여러 SNS에 발행까지 이어 주는 개인 서재입니다.

- 주소(GitHub Pages 사용 시): `https://<계정>.github.io/cocoro/library/`
- 설치할 것 없음: `library/index.html` 파일 하나로 동작합니다.

## 탭 구성

| 탭 | 하는 일 |
|---|---|
| ✍️ 메모하기 | 메모 → **✨ 글로 완성하기** → AI가 제목·본문·분류·태그를 붙여 초안 작성 → 다듬고 저장 |
| 📚 서재 | 분류별로 모아 보기, 검색, 열람, 수정, 삭제, 마크다운으로 내려받기 |
| 🖌 캘리그라피 | 작품 사진 업로드 → AI가 글귀를 읽고 제목·해설 작성 → 갤러리에 저장 |
| 📤 발행하기 | 글/작품 선택 → **✨ 플랫폼별 문구 만들기** → 플랫폼마다 복사·공유·자동 발행 |
| ⚙️ 설정 | Claude API 키, 나의 문체, 분류 목록, 웹훅, 백업/불러오기 |

## 처음 설정

1. [Anthropic 콘솔](https://console.anthropic.com/settings/keys)에서 API 키를 발급해 **설정 → API 키**에 넣습니다.
   키가 없어도 **프롬프트 복사** 버튼으로 Claude 앱(claude.ai)에서 같은 작업을 할 수 있습니다.
2. **나의 문체·관점**을 적어 두면 모든 글이 그 결로 다듬어집니다.
3. **분류**는 기본값(사회계약·정책 / 경제 생태계 / 공동체·관계 / AI 대전환 / 삶·성찰 / 캘리그라피 글귀 / 기타)에서 자유롭게 바꿀 수 있습니다.

## 저장과 백업

- 글과 이미지는 **지금 쓰는 브라우저 안(IndexedDB)**에 저장됩니다. 서버에 올라가지 않습니다.
- 브라우저 데이터를 지우면 함께 사라지므로 **설정 → 전체 백업 내려받기**를 정기적으로 해 주세요.
  백업 파일(JSON)에는 글과 이미지가 모두 들어가며, API 키와 웹훅 주소는 들어가지 않습니다.
- 다른 기기(휴대폰 등)로 옮길 때는 백업 파일을 **불러오기** 하면 됩니다.
