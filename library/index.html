발행하기

서재의 글이나 작품을 고르면, 플랫폼마다 알맞게 다듬은 게시 문구를 만들어 드립니다. 자동 표시는 설정의 웹훅(Make·Zapier)으로 바로 올라가고, 반자동은 복사·공유 버튼으로 한 번에 올리는 방식입니다.

AI 연결 (Claude)

메모를 글로 완성할 때 사용합니다. Anthropic 콘솔에서 API 키를 발급받아 넣어 주세요. 키는 이 기기 브라우저에만 저장되며 Anthropic 외 어디에도 전송되지 않습니다. 공용 PC에서는 넣지 마세요.

분류 (서재의 칸)

한 줄에 하나씩. 언제든 늘리거나 고칠 수 있어요.

자동 발행 연결 (웹훅)

Make.com 또는 Zapier에서 만든 웹훅 주소를 넣으면 ‘자동 발행’ 버튼이 이 주소로 글·이미지를 보냅니다. 연결 방법은 library/AUTOMATION.md에 정리해 두었습니다.

백업 · 옮기기

서재는 이 브라우저에 저장됩니다. 정기적으로 백업 파일을 내려받아 두세요. 다른 기기에서는 ‘불러오기’로 옮길 수 있습니다.
